## Redistribution and Privacy Notes

This repository is intended to remain private.

Reasons:

- it contains raw benchmark images
- third-party data terms may not match unrestricted redistribution
- generated review bundles contain copied originals from benchmark inputs

From the official ADE20K materials, the benchmark distinguishes between:

- images and benchmark content intended for research/educational use
- annotation/software materials that are separately distributed

Do not assume a single permissive license applies to the entire repository.

Before making any part of this repository public, re-check the original ADE20K terms directly from the official source.

- `docs/review/`

Preserved export snapshot:

- `site_exports/ade20k_texture_miner_site/`

## Why Some Large Artifacts Are Not Included

This repository does not include the external `/path/to/rwtd_runs` tree from the broader mixed workspace.

That directory was not repository-resident, is much larger than the Detecture extraction target, and mixes other datasets and experiments that are outside the narrower Detecture boundary.

For Detecture, the canonical retained artifacts are:

- source code
- configuration
- raw ADE20K benchmark copy
- bundled review data
- ADE20K-only site export
- progress diagnostics

## Reproduction Notes

To reproduce the ADE20K Detecture evaluation with the included raw data:

```bash
bash scripts/run_detecture_ade20k.sh \
  --out /path/to/detecture_ade20k_eval \
  --ade_root /path/to/Detecture/data/raw/ade20k/ADEChallengeData2016 \
  --skip_download
```

To inspect the included review bundle:

```bash
xdg-open docs/review/index.html
```
